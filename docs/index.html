🥷 Ultrastealth — this project

Headed real-Chrome automation that passes bot detection.

Use it for
  • Highly protected sites (Cloudflare, Imperva, DataDome)
  • JS-rendered SPAs with no usable API
  • Tasks needing clicks, forms, multi-step flows

⚡ scrapling-js — sibling

Pure-HTTP, no-browser fetching with TLS impersonation.

Use it for
  • JSON APIs & embedded JSON (__NEXT_DATA__)
  • Maximum speed & throughput (no browser)
  • Cloudflare Workers / edge deploys

Why it stays invisible

Detection is fought at the driver, the browser, and the page — not just with a spoofed user-agent.

Driver-level patch

Renames rebrowser-playwright's leaked __pwInitScripts / UtilityScript identifiers at the driver source. Lifts the rebrowser bot score 6/10 → 8/10.

Isolated-world evaluate

REBROWSER_PATCHES_RUNTIME_FIX_MODE=alwaysIsolated runs page.evaluate off the main world → 0 positive detections on rebrowser's probe.

Headed, not headless

Launches real Chrome under Xvfb with a curated flag set — no headless tells, automation flags stripped, navigator.webdriver:false.

Undetectable bypasses

Optional WebGL/canvas/audio/font spoofs use Proxy native-masking (toString/name read native) and stay OS-consistent. Opt in with ULTRASTEALTH_BYPASSES=on.

WebRTC leak closed

Camoufox-ported webrtc_spoof.js drops real-IP ICE candidates so a proxy isn't betrayed by a WebRTC IP leak.

Network DevTools for agents

The MCP exposes Chrome-DevTools-style capture (browser_network_log/_detail/_response_body) — perfect for discovering JSON APIs.

1Install the MCP server

Give your coding agent a stealth browser it can drive: navigate, click, type, screenshot, and capture network traffic — all anti-detection.

Setup once

# Install ultrastealth + the MCP server (exposes the `ultrastealth-mcp` command)
pipx install --include-deps git+https://github.com/anusoft/ultrastealth.git

# Install the Chromium build rebrowser drives, then patch the driver's CDP leaks
rebrowser_playwright install chromium   # note: underscore — that's the pipx-exposed name
ultrastealth-patch            # re-run after any `pipx upgrade ultrastealth`

Linux headed mode needs an X server — sudo apt install xvfb and run your agent under xvfb-run -a (or set DISPLAY). Prefer not to use pipx? See the clone install below.

Then wire it into your tool

claude mcp add ultrastealth -- ultrastealth-mcp --transport stdio

      "command": "ultrastealth-mcp",

codex mcp add ultrastealth -- ultrastealth-mcp --transport stdio

      "type": "local",

Add to ~/.cursor/mcp.json (global) or .cursor/mcp.json (project)

{

    "ultrastealth": {
      "command": "ultrastealth-mcp",

Enable it under Settings → MCP, then call its tools from chat.

Alternative: one shared HTTP server (always-on, multi-tool)

Run the server once and point every tool at a URL instead of spawning a process each:

ultrastealth-mcp --port 8090          # serves http://localhost:8090/mcp
  • Claude Code: claude mcp add --transport http ultrastealth http://localhost:8090/mcp
  • Cursor: { "mcpServers": { "ultrastealth": { "url": "http://localhost:8090/mcp" } } }
  • OpenCode: { "mcp": { "ultrastealth": { "type": "remote", "url": "http://localhost:8090/mcp", "enabled": true } } }
Alternative: clone install (no pipx) 
git clone https://github.com/anusoft/ultrastealth.git
cd ultrastealth
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
rebrowser_playwright install chromium
python3 -m ultrastealth.patch_rebrowser

Then use "command": "python3", "args": ["-m","ultrastealth.mcp_server","--transport","stdio"] and set the tool's working directory (or MCP cwd) to the clone.

2Install the script-authoring skill

craft-scraper runs a one-time LLM authoring loop and emits a reusable, deterministic script that reruns forever with no LLM. It uses the MCP to inspect the site, then writes a scrapling-js script (fast, for APIs) or an Ultrastealth script (for protected/JS sites) — automatically picking the right one.

One command — installs into whatever agent you use

# the `skills` CLI (vercel-labs/skills) auto-detects your agent and
# installs to the right place — Claude Code, Codex, Cursor, OpenCode + 70 more
npx skills add anusoft/ultrastealth --skill craft-scraper

Detects installed agents automatically; if it can't, it asks which to use. Run inside a project for project scope, or add -g for global (~/.claude/skills/ etc.). Bun users: bunx skills add … works the same.

Pick agents explicitly / non-interactive (CI)

npx skills add anusoft/ultrastealth --skill craft-scraper -g -y \
  -a claude-code -a codex -a cursor -a opencode

After installing, just ask — or run /craft-scraper <task + url>. Manage with npx skills list / update / remove.

Manual install (no skills CLI) 
git clone --depth 1 https://github.com/anusoft/ultrastealth.git /tmp/ultrastealth
mkdir -p ~/.claude/skills          # or your agent's skills dir
cp -r /tmp/ultrastealth/skills/craft-scraper ~/.claude/skills/

The skill is plain Markdown (skills/craft-scraper/SKILL.md + reference/), so it also drops in as any tool's native prompt/command/rule.

3What it looks like

Ask once. Get a script you can rerun forever.

You ▸ /craft-scraper download every product from shop.example.com/catalog

Agent ▸ browser_network_enable()            # MCP: stealth browser
        browser_navigate("…/catalog")
        browser_network_log(filter_type="xhr")
        → found JSON API  /api/products?page=N   ✓ Path A (speed)
        ↳ writes  scrape_example.js  (scrapling-js, no browser at runtime)
        bun run scrape_example.js  → 1,284 products across 13 pages ✓

# rerun anytime, no LLM:
bun run scrape_example.js --resume

No API and Cloudflare in the way? The agent falls back to Path B and emits an Ultrastealth headed Python script instead — same skill, same command. For Cloudflare-Turnstile-gated sites it builds in a persistent browser profile + challenge-solving (and notes that those targets need a residential IP). See the worked example examples/egp-announcements.py in the repo.

Or use it as a library

import asyncio
from ultrastealth import UltrastealthFetcher

async def main():
    async with UltrastealthFetcher(headless=False) as us:   # headed + Xvfb = stealthiest
        html = await us.fetch_and_evaluate(
            url="https://bot.sannysoft.com/",
            js_expression="() => document.documentElement.outerHTML",
            wait_secs=3.0,
        )
        print(html[:500])

asyncio.run(main())
