Ultrastealth.

Maximum-stealth browser automation in Python — real Chrome under Xvfb, rebrowser-playwright with CDP-leak fixes, and undetectable, OS-consistent JS bypasses.

View on GitHub Documentation

Why

Driver-level stealth

Patches the bundled driver's __pwInitScripts / UtilityScript leaks and runs page.evaluate in an isolated world so main-world execution is undetectable.

Headed, not headless

Launches real Chrome under Xvfb with a curated flag set — no headless tells, automation flags stripped.

Cloudflare-aware

Built-in Turnstile / interstitial solver for JS challenges that block raw HTTP clients.

Undetectable bypasses

Optional JS spoofs use Proxy-based native masking (toString/name read native) and stay OS-consistent. Off by default — opt in with ULTRASTEALTH_BYPASSES=on.

MCP server

Ships a Model Context Protocol server so agents can drive a stealth browser with click / type / navigate tools.

Standalone

Pure Python package, no framework lock-in. Async UltrastealthFetcher API.

Quick start

git clone https://github.com/anusoft/ultrastealth
cd ultrastealth
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m ultrastealth.patch_rebrowser   # patch the driver leaks
import asyncio
from ultrastealth import UltrastealthFetcher

async def main():
    async with UltrastealthFetcher(headless=False) as us:
        html = await us.fetch_and_evaluate(
            url="https://bot.sannysoft.com/",
            js_expression="() => document.documentElement.outerHTML",
            wait_secs=3.0,
        )
        print(html[:500])

asyncio.run(main())
