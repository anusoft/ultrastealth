# Prior art: Playwright-patching / CDP-leak elimination

> **Thesis.** Ultrastealth's stealth floor is set by a dependency that stopped moving: `rebrowser/rebrowser-patches` last shipped **2025-05-09**, and the installed `rebrowser-playwright` is pinned to **Playwright 1.52.0** (`rebrowser_playwright-1.52.0.dist-info`). `patchright` tracks Playwright **1.59.x** on an automated release pipeline that polls `microsoft/playwright` and rebuilds on every upstream tag. On the one vector both projects care most about — `Runtime.enable` — they are at parity, and rebrowser's design is arguably cleaner. Where patchright is decisively ahead is everything *around* it: the `__playwright__binding__` global is deleted rather than raced against, `__pwInitScripts` is designed out rather than renamed, init scripts reach the main world through HTML injection instead of `Page.addScriptToEvaluateOnNewDocument`, and eight of Playwright's default switches that ultrastealth *re-adds by hand* are stripped. Patchright is the answer, but it is not free: it disables the Console domain outright and buys main-world init scripts with a catch-all network route.

**Read date:** 2026-07-30. Claims are from source in `/Users/mac/Projects/_prior-art/` and the installed driver at `/Users/mac/.local/pipx/venvs/ultrastealth/lib/python3.14/site-packages/rebrowser_playwright/`. Inferences are marked *(inferred)*.

**Licenses:** `patchright` and `patchright-python` are **Apache-2.0** (both `LICENSE` files). Ultrastealth is **MIT**. Permissive and compatible — Apache-2.0 adds a NOTICE/attribution obligation and a patent grant that MIT lacks; no copyleft risk.

**Reading the 6/10.** The four non-passing rebrowser bot-detector rows in `docs/research/bot_benchmark_default_2026-06-29.json` are all `severity: "skip"`, not `"fail"` — `dummyFn`, `sourceUrlLeak`, `getElementsByClassName`, `exposeFunctionLeak`. They are *untriggered*, because `REBROWSER_PATCHES_RUNTIME_FIX_MODE=alwaysIsolated` (`fetcher.py:600`) means `page.evaluate` can never touch main-world objects, so the detector's instrumented `window.dummyFn` and monkey-patched `document.getElementById` are never reached. **Ultrastealth scores 6/10 by abstaining, not by passing.** Patchright's `isolated_context=False` lets you actually run those four probes — and its own `detection_smoke_test.mjs` runs every assertion in the main world and expects zero leaks.

## patchright — how it works

Not a runtime monkeypatch and not a post-install rewrite. `patchright` is a **source-level fork-and-build**:

1. `/Users/mac/Projects/_prior-art/patchright/patchright_driver_patch.ts` drives ~40 patch modules in `driver_patches/` over a checked-out `microsoft/playwright` tree using **ts-morph AST manipulation** — `getClassOrThrow("CRPage")`, `getMethodOrThrow("_initialize")`, `getVariableDeclarationOrThrow("chromiumSwitches")`. It also mutates `packages/protocol/spec/*.yml` to add `isolatedContext`, `focusControl` and `patchrightInitScript` to the wire protocol.
2. The patched tree is **built** into a driver bundle and published as a GitHub release zip. `patchright-python/patch_python_package.py` separately rewrites `playwright-python` (again via `ast`, not regex) into the `patchright` package and repoints the driver download at those releases.
3. `patchright.patch` (1.9 MB) is a generated documentation artefact of the whole diff — the idea is credited to rebrowser in the README.

**Version-drift handling is the strongest part.** `utils/release_version_check.sh` polls `microsoft/playwright`'s latest release and triggers a rebuild if patchright lacks that tag. `utils/extract_patched_symbols.ts` + `utils/check_patch_impact.ts` diff old→new Playwright and classify every patched symbol as `signature_changed | body_changed | symbol_removed | symbol_added | unchanged`. `utils/detection_smoke_test.mjs` is a runtime regression test asserting no `__pw*` globals and zero `Error.stack` reads across page, iframe and popup.

Compared with `patch_rebrowser.py`: ultrastealth's anchor-on-original-token + exact-count + warn-on-drift design is good *for what it is* — ten renames over a shipped bundle, idempotent and revertible — but structurally capped. It cannot delete a CDP call, add a protocol parameter, or change control flow. Patchright edits TypeScript before the bundler runs, so it can; the price is rebuilding the whole driver, which is why it needs CI and why ultrastealth cannot replicate the approach in-tree.

## Migration assessment: rebrowser-playwright → patchright

**API-surface delta vs ultrastealth's actual usage.** Every call ultrastealth makes is preserved:

| Ultrastealth call site | Status under patchright |
|---|---|
| `async_playwright()` (`fetcher.py:603`, `bot_benchmark.py:343,514`) | identical — `from patchright.async_api import async_playwright` |
| `chromium.launch_persistent_context(...)` (`fetcher.py:693`) | identical; gains optional `focus_control` |
| `connect_over_cdp(...)` (`bot_benchmark.py:351,522`) | present; **but a CDP-attached browser gets none of patchright's launch-time patches** — the stealth lives in the server process, so the benchmark's CDP path degrades to plain Playwright *(inferred)* |
| `context.add_init_script(str)` (`fetcher.py:744`) | works, **but silently installs a `**/*` fallback route** (`patch_python_package.py`, `install_inject_route`) — every document request is now intercepted |
| `page.evaluate(...)` (13 sites in `fetcher.py`, `browser_core.py:296`) | works; `isolated_context=True` by default, matching today's `alwaysIsolated` semantics |
| `page.accessibility.snapshot()` (`browser_core.py:103`) | **must be verified.** `page.accessibility` is deprecated upstream; ultrastealth's whole `eN` ref system depends on it and the jump is 1.52→1.59 |
| `page.title()` 20 s health ping (daemon) | unaffected — patchright does not break `title()`/`evaluate` the way rebrowser's `alwaysIsolated` breaks main-world reads |
| `_context._browser` / `_impl_obj._browser` (`mcp_server.py:368-377`) | private attributes; may have moved between 1.52 and 1.59 |

**Would `patch_rebrowser.py` still be needed?** Partly, and the two are **stackable, not mutually exclusive** — patchright ships a driver package on disk with the same `lib/server/…`, `lib/generated/…` layout, so the same rename pass could run against it. Of its three renames: `__pwInitScripts` becomes a no-op (the token is gone, and the script's `drifted` branch would correctly WARN-and-skip rather than corrupt). `UtilityScript` is still worth applying — patchright does not rename it, and it is the one place ultrastealth is measurably ahead. `__playwright_builtins__` is worth applying too, as insurance for main-world `evaluate`. So: keep the script, retarget the driver-root resolver, expect two of ten files to report `drifted`.

**Risks / unknowns.**
- **Console is gone.** `page.on("console")`, `page.on("pageerror")`, worker console and worker errors are all disabled — `patchright-python/utils/modify_tests.py:5-45` skips `test_console.py`, `test_page_event_console.py`, `test_page_event_pageerror.py` wholesale.
- **Other documented breakage** (same file): WebSocket routing; tracing with resources / tracing groups / trace sources; `expose_function` from inside `add_init_script`; in-process popup init scripts; request-header arrays; drag/drop `dispatchEvent` can hang.
- **The catch-all route is a perf and correctness surface.** Every HTML document is fulfilled through Node, has its CSP headers *and* meta tags rewritten, and is re-served. Not free at crawler scale.
- **Chromium only** (irrelevant here), and **a single maintainer with proxy-vendor sponsorships** — but 3.9k★ and a 2026-07-16 commit beat a 14-month-dead dependency.

**Verdict: adopt-with-caveats, behind a runner flag.** Add `patchright` as an optional engine selected by `ULTRASTEALTH_ENGINE`, keep `rebrowser-playwright` as the default until the benchmark says otherwise, and let `bot_benchmark.py` run both. Do **not** rip out `patch_rebrowser.py` — retarget it. The `import` swap is one line; the risk is concentrated in `accessibility.snapshot()`, the console handlers and the route overhead, all of which are measurable in an afternoon.
